\abstract{%
This paper analyzes RFID-based traceability systems for perishable products using stochastic modeling. Economic Traceability Lot ($n^*\approx250$) maximizes profit compared to no-traceability scenarios with improvements up to 1005.6\%. Cost-benefit analysis and numerical results validate practical applicability.
}

\keywords{RFID, traceability, supply chain, perishable products, Economic Traceability Lot}

\section{Introduction}

Оптимизация логистики скоропортящихся продуктов критически важна из-за требований безопасности \cite{Alarcos1999}. Трассируемость по ISO 9001:2000 локализует дефектные партии \cite{ArslanHansen1996}.

\begin{itemize}
\item Практическая реализация: сквозной обмен данными
\item Экономическая мотивация: укрепление репутации \cite{WangEtAl2015}
\item Технические вызовы: затраты внедрения \cite{BartkovaJouvet1999}
\end{itemize}

\section{Cost Structure}

Затраты включают персонал, оборудование, обучение и RFID-метки \cite{BartkovaJouvet1999}.

\begin{enumerate}
\item Персонал: время сотрудников
\item Оборудование: сканеры, ПО
\item Обучение персонала
\item Консультанты
\item Расходники: RFID-метки
\end{enumerate}

Меньший размер партии повышает точность локализации \cite{Mitchell2001}.

\subsection{Cost-Benefit Analysis}

Полезность трассировки:
\begin{equation}
\text{CBR}(n) = \frac{(1-G(n))C_{\text{recall}}}{C_{\text{tag}}G(n)^{-1}+C_{\text{infra}}}
\label{eq:cbr}
\end{equation}

где $G(n)=P/n$ -- гранулярность, $P$ -- объём, $n$ -- партия.

\section{Supply Chain Model}

Модель: производитель-ритейлер. Гранулярность:
\begin{equation}
G(n)=\frac{P}{n}
\label{eq:granularity}
\end{equation}

Приёмочный контроль с порогом $th$.

\subsection{Economic Traceability Lot}

Прибыль:
\begin{equation}
\pi(n)=P_r(1-p)n\operatorname{Pr}(\hat{p}\leq th)-C_{tr}\frac{P}{n}
\label{eq:profit}
\end{equation}

Оптимум: $n^*=\arg\max_n[\pi(n)]$.
